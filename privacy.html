FrameNote privacy policy

Effective November 11, 2026

Your notebook stays on your computer

FrameNote has no accounts, analytics, ads or backend. It does not send notes, captions or page information to a server, or sell or share that data.

What FrameNote processes

On permitted HTTP/HTTPS pages and accessible frames, FrameNote discovers media players and reads playback state, nearby headings and identifiers. Saved annotations include your comment, timestamp, accessible captions, page URL, tab title, heading and player identity. Media source paths can be included; media-source query parameters and temporary blob URLs are excluded. FrameNote does not maintain a browsing-history log. Page URLs and notes can contain private information.

Storage and backups

Saved notes, settings and backup tracking live in browser extension storage. Drafts stay in their tab’s memory and are lost on document reload. Automatic JSON backups use ordinary browser downloads into a FrameNote subfolder of your configured download location. Manual backups use Save As, asking for a destination for that single file. FrameNote monitors downloads and queries its own monthly backup records in download history. It does not browse directory contents or request direct folder permission.

The current backup updates after changes, while monthly snapshots retain their contents. Lost tracking/history can cause an extra numbered monthly file. On first use, current-file numbering preserves files from older installs. Backups are readable JSON. The browser keeps download metadata. Other software with relevant computer/browser permissions can access these local files/data; if another application syncs the backup location, its settings apply.

Your controls

You can edit/delete notes, import/export JSON, disable automatic backups, change the browser’s download location, choose a manual Save As destination, revoke extension permissions, or uninstall. Uninstalling removes extension storage and tracking; completed files remain on disk. Deleting a note updates the current automatic backup when enabled; older monthly snapshots and exports may still contain it. FrameNote never automatically deletes files.

Permissions and older versions

Website access discovers media and displays annotations. Storage saves notes/settings/tracking; alarms check monthly/missing downloads and retries; downloads starts and monitors backups and checks matching download records. No companion app, File System Access API or Brave flag is needed. Previously selected folder handles are no longer used. Older browser folder grants are not automatically revoked; you can revoke them in browser controls.
