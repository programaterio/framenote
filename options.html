A little help

How are backups kept?

Current backups start as framenote-current.json; an existing file gets a numbered name on first use. Monthly snapshots use framenote-YYYY-MM.json and are never overwritten.

FrameNote tracks downloads, not folder contents. Lost tracking/history may create an extra monthly file. Sleep or shutdown delays backups.

Can I change the backup location?

Automatic backups follow browser Settings → Downloads → Location. That affects other downloads too. Manual Save As lets you choose any permitted folder for one backup.

Updating or reinstalling

For updates, keep the same installation folder, replace its files, click Reload on the extensions page, and refresh media tabs.

Uninstalling removes browser notes and settings; backup files remain. Import a JSON backup to restore your notes.

What permissions are needed?

Backups use normal browser downloads. No Brave API flag, companion app or ongoing folder access is needed. Old folder grants are no longer used and can be revoked in browser settings.

No player or subtitles?

Refresh the page, start playback, and allow FrameNote on the site. Enable captions before capturing. Some closed or sandboxed players cannot be accessed; audio is not transcribed.
